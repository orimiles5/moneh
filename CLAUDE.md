# Moneh

Taxi meter on the driver's phone; running fare on the car screen. Israel first, Hebrew/RTL default. Full brief: `docs/brief.md`.

## Layout
- `core/` – Kotlin Multiplatform. Fare engine, tariffs, trip state machine, distance pipeline, hash-chained trip log, Hebrew calendar. Pure: no clocks, no I/O.
- `ios/` – SwiftUI app + Live Activity extension. Consumes core as an XCFramework. Project generated by XcodeGen from `ios/project.yml`.
- `android/` – Compose app (milestone 5; iOS ships first).
- `docs/` – regulatory notes, open questions, tariff sources.

## Rules
- Money is `Long` agorot. Never floating point for money.
- Tariffs are versioned JSON data with source URL + effective dates. Never invent tariff values; unknowns go to `docs/open-questions.md`.
- Israeli fare rules and their legal sources: `docs/tariffs-il.md`. Prices in the order are VAT-exclusive; time and distance charges add up.
- No user-facing string literals in code: String Catalogs (iOS), string resources (Android). Hebrew + English.
- Leading/trailing only, never left/right. Fare digits are tabular (Heebo's digits are tabular by default).
- Swift 6 language mode, strict concurrency. No force unwraps / `!!` outside tests.
- Comments only for non-obvious *why*.
- The app is not a certified meter; UI must never claim it is.
- App name lives in `ios/Config/App.xcconfig` (`APP_DISPLAY_NAME`) and Gradle property `appName`.

## Workflow
- Branches `feat/… fix/… chore/… docs/…`, Conventional Commits, one coherent change per PR, link the issue.
- Squash-merge own PRs once CI is green, **except** changes to fare calculation, tariffs, trip log or permissions: leave open for owner review.
- After code changes: `graphify update .` if `graphify-out/` exists.

## Commands
- Core tests: `./gradlew :core:allTests` (JVM fast path: `./gradlew :core:jvmTest`)
- Core lint: `./gradlew ktlintCheck detekt`
- XCFramework: `./gradlew :core:assembleMonehCoreReleaseXCFramework`
- iOS project: `cd ios && xcodegen`; build/test: `xcodebuild -project ios/Moneh.xcodeproj -scheme Moneh -destination 'platform=iOS Simulator,name=iPhone 17' test`
- iOS lint: `swiftlint --strict` and `swiftformat --lint ios`
- Snapshot references are recorded on CI (`macos-26` runner); local runs on another iOS version will mismatch. To re-record, delete the PNGs, push, and download the `snapshots` artifact from the failed run.
